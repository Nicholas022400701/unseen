UNSEEN / 1.0.0
Made for the missing candidates.

The list is only half the story.

  1. Pick an item. Inspect all hard blockers, score contributions and the slot-by-slot selection trace.
  2. Find minimal repairs. The engine tries every subset of up to 8 listed changes. No successful strict subset means an inclusion-minimal repair.
  3. Apply and compare. See who enters, who leaves, and undo without losing the original scenario.
  4. Bring your own candidates. Import schema-1 JSON (1–120 items, up to 256 KiB). Export a demo to learn the format.

Small on purpose

Interest, quality and freshness are supplied numbers, not predictions. Retrieval is a supplied boolean, not a search engine. Topic diversity is a greedy penalty, not DPP. Exactness is limited to the declared action menu, not every possible policy.

Zero-action results mean the target already appears. “No repair” means only that none of these allowed combinations works. Reports contain your input data: review them before sharing.

Keyboard: Tab to controls, arrow keys for sliders, Enter or Space to act, Escape to close dialogs. Changes remain in memory until you reload.

Take the experiment with you.

Scenario JSON can be re-imported. Report JSON is a complete inspection record, not an importable scenario.
